## Directory Purposes

**`lua/config/`:**
- Purpose: Core editor configuration that does not depend on any plugin
- Contains: Lua modules loaded via `require()` from `init.lua`
- Key files: `options.lua` (must load first -- plugins depend on options like `termguicolors`), `helpscreen.lua` (only module with a `setup()` function)

**`lua/plugins/`:**
- Purpose: Plugin declarations using lazy.nvim spec format
- Contains: One Lua file per functional concern, each returning a table or list of tables
- Key files: `lsp.lua` (largest and most complex -- contains file-level diagnostic config + autocmds + plugin specs), `completion.lua` (blink.cmp must load before lspconfig)

## Key File Locations

**Entry Points:**
- `init.lua`: Neovim configuration entry point; controls load order of everything

**Configuration:**
- `.luacheckrc`: Static analysis config for luacheck linter (declares `vim` global, sets luajit std)
- `.gitignore`: Contains only `lazy-lock.json`

**Core Logic:**
- `lua/config/options.lua`: All `vim.opt` settings
- `lua/config/keymaps.lua`: All global (non-plugin, non-LSP) keymaps
- `lua/config/autocmds.lua`: All global autocommands
- `lua/config/helpscreen.lua`: Custom help screen floating window (the only custom "feature" module)

**Plugin Config:**
- `lua/plugins/lsp.lua`: LSP server configuration, diagnostic settings, LspAttach keymaps
- `lua/plugins/formatting.lua`: Formatter-per-filetype mapping and format-on-save config
- `lua/plugins/linting.lua`: Linter-per-filetype mapping and tool auto-installation list
- `lua/plugins/completion.lua`: Completion engine sources and keymap configuration

## Naming Conventions

**Files:**
- `lowercase.lua`: All files use lowercase with no separators
- Config modules named by concern: `options`, `keymaps`, `autocmds`, `helpscreen`
- Plugin files named by functional area: `lsp`, `git`, `formatting`, `linting`, `completion`, `diagnostics`, `filetree`, `terminal`, `statusline`, `colorscheme`, `treesitter`, `qol`, `deps`

**Directories:**
- `config/`: Editor-native configuration (no plugin dependencies)
- `plugins/`: Plugin specifications (all files auto-discovered by lazy.nvim)

**Autocommand Groups:**
- Project-specific groups use `project-` prefix: `project-lsp-attach`, `project-lint`, `project-diag-float`
- Config-level groups use descriptive names: `highlight_yank`, `restore_cursor`, `strip_whitespace`, `json_conceal`, `filetype_indent`, `helpscreen_startup`

## Where to Add New Code

**New Editor Option or Global Setting:**
- Add to `lua/config/options.lua`

**New Global Keymap (not plugin-specific):**
- Add to `lua/config/keymaps.lua`
- Always include `desc` parameter for which-key discovery

**New Autocommand (not plugin-specific):**
- Add to `lua/config/autocmds.lua`
- Always create a named augroup with `clear = true`

**New Plugin:**
- Create new file in `lua/plugins/` named after the functional area (e.g., `lua/plugins/search.lua`)
- Return a lazy.nvim spec table or list of tables
- Prefer `opts` style over `config` function unless imperative code is required
- If the plugin shares dependencies already in `lua/plugins/deps.lua`, list them in `dependencies` for load-order but they will be deduplicated by lazy.nvim

**New Formatter for a Language:**
- Add formatter name to `formatters_by_ft` in `lua/plugins/formatting.lua`
- Add binary name to `ensure_installed` list in `lua/plugins/linting.lua` (mason-tool-installer handles both formatters and linters)

**New Linter for a Language:**
- Add linter name to `linters_by_ft` in `lua/plugins/linting.lua`
- Add binary name to `ensure_installed` list in the same file

**New LSP Server:**
- Add server name to `ensure_installed` in `lua/plugins/lsp.lua`
- If custom settings needed, add `vim.lsp.config("server_name", { settings = {...} })` call BEFORE `require("mason-lspconfig").setup(opts)` in the config function
- Add corresponding treesitter parser to `ensure_installed` in `lua/plugins/treesitter.lua`

**New Keybinding Help Entry:**
- Add line to `build_lines()` function in `lua/config/helpscreen.lua`

**New which-key Group Label:**
- Add to `opts.spec` table in `lua/plugins/qol.lua`

## Special Directories

**`.planning/`:**
- Purpose: Project planning and analysis documents
- Generated: Manually by tooling
- Committed: Yes

**`lazy-lock.json`:**
- Purpose: Pinned plugin commit hashes (like a lockfile)
- Generated: Yes, by lazy.nvim
- Committed: No (listed in `.gitignore`)
